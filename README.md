# Grid Tower Defense: Башни и Энергия (Вариант 23)

Сквозной проект в жанре «Защита башен» (Tower Defense), выполненный в рамках курса. 
Главная особенность — башни не работают сами по себе, им требуется проведение энергетических линий от главного генератора.

## 🚀 Статус проекта
На данный момент реализованы **Лабораторные работы №1, №2 и №3**.

## 🛠 Стек технологий
* **Игра:** Python 3.9+, Pygame
* **Telegram-бот:** Aiogram 3.x, Asyncio
* **Данные:** JSON (конфиги), CSV (статистика), TXT (логи)

## 📂 Структура проекта

### 🎮 Игровое ядро (ЛР 1)
* `PythonApplication2.py` — главный файл запуска игры, игровой цикл.
* `monster.py`, `tower.py`, `generator.py` — классы игровых сущностей.
* `energy_network.py` — алгоритм поиска минимального остовного дерева для энергосети.
* `level.py`, `hud.py`, `constants.py` — вспомогательные модули.

### 💾 Работа с файлами (ЛР 2)
* `config_loader.py` — парсинг и валидация JSON-конфигураций (с обработкой ошибок).
* `logging_utils.py` — модуль логирования волн и создания CSV-таблиц статистики.
* `data/grid_level.json` — настройки уровня (путь, генератор, волны, стартовое золото).
* `data/defense_balances.json` — характеристики монстров и башен.

### 🤖 Telegram-бот «Инженер Обороны» (ЛР 3)
* `bot/main.py` — асинхронный запуск бота, хэндлеры кнопок и текстовых команд.
* `bot/analytics.py` — модуль чтения логов игры, расчет статистики и ачивок.
* `bot/sessions/` — JSON-сессии пользователей (Stateless архитектура).
* `config.py` — секретный файл с токеном бота (игнорируется Git).

## 📊 Логирование и статистика
Во время игры в папке `output/` автоматически создаются файлы:
1. `log_defense.txt` — пошаговый лог каждой волны и итог сессии.
2. `towers_built.csv` — таблица со статистикой всех построенных башен.
3. `defense_stats.csv` — итоговая таблица сессий (имя, волны, убийства, золото, исход).
