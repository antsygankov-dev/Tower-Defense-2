# Grid Tower Defense: Башни и Энергия (Вариант 23)

Проект в жанре «Защита башен» (Tower Defense), выполненный в рамках сквозного курсового проекта. 
Главная особенность игры — башни не работают сами по себе, им требуется проведение энергетических линий (энергосети) от главного генератора.

## 🚀 Текущий статус
На данный момент реализованы **Лабораторная работа №1** и **Лабораторная работа №2**.

## 🛠 Стек технологий
* **Язык:** Python 3.9+
* **Библиотеки:** Pygame
* **Формат данных:** JSON, CSV, TXT

## 📂 Структура проекта

### Основная логика (ЛР 1)
* `PythonApplication2.py` — главный файл запуска, игровой цикл и обработка событий.
* `monster.py` — логика движения монстров по маршруту.
* `tower.py` — логика поиска цели в радиусе и атаки башен.
* `energy_network.py` — алгоритм проверки связности энергосети.
* `generator.py`, `hud.py`, `level.py` — вспомогательные модули для отрисовки и работы уровня.
* `constants.py` — базовые константы проекта.

### Работа с файлами и данными (ЛР 2)
* `config_loader.py` — модуль парсинга и валидации JSON-конфигураций (обработка ошибок через `try-except`).
* `logging_utils.py` — модуль логирования волн и создания CSV-таблиц статистики.
* `data/grid_level.json` — конфигурация уровня (координаты пути, генератора, волны, стартовое золото).
* `data/defense_balances.json` — характеристики монстров и башен.

## 📊 Логирование и статистика (ЛР 2)
Во время игры (или после её завершения) в папке `output/` автоматически создаются следующие файлы:
1. `log_defense.txt` — пошаговый лог каждой волны (количество заспавненных, убитых, утекших монстров, потраченное и заработанное золото) и итог сессии.
2. `towers_built.csv` — таблица со статистикой всех построенных башен (тип, координаты, урон, убийства, подключение к сети).
3. `defense_stats.csv` — итоговая таблица сессий (имя игрока, число отбитых волн, всего убийств, заработанное золото, исход).
